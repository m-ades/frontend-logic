G. Which of the following is possible? If it is possible, give an example. If it is not possible, explain why.

  1. 1.
    ​

    A valid argument that has one false premise and one true premise

  2. Yes: ‘All whales are mammals (true). All mammals are plants (false). So all whales are plants.’

  3. 2.
    ​

    A valid argument that has a false conclusion

  4. Yes. (See example from previous exercise.)

  5. 3.
    ​

    A valid argument, the conclusion of which is a necessary falsehood

  6. Yes: ‘1+1=3. So 1+2=4.’

  7. 4.
    ​

    An invalid argument, the conclusion of which is a necessary truth

  8. No. If the conclusion is necessarily true, then there is no way to make it false, and hence no way to make it false whilst making all the premises true.

  9. 5.
    ​

    A necessary truth that is contingent

  10. No. If a sentence is a necessary truth, it cannot possibly be false, but a contingent sentence can be false.

  11. 6.
    ​

    Two necessarily equivalent sentences, both of which are necessary truths

  12. Yes: ‘4 is even’, ‘4 is divisible by 2’.

  13. 7.
    ​

    Two necessarily equivalent sentences, one of which is a necessary truth and one of which is contingent

  14. No. A necessary truth cannot possibly be false, while a contingent sentence can be false. So in any situation in which the contingent sentence is false, it will have a different truth value from the necessary truth. Thus they will not necessarily have the same truth value, and so will not be equivalent.

  15. 8.
    ​

    Two necessarily equivalent sentences that together are jointly impossible

  16. Yes: ‘1+1=4’ and ‘1+1=3’.

  17. 9.
    ​

    A jointly possible collection of sentences that contains a necessary falsehood

  18. No. If a sentence is necessarily false, there is no way to make it true, let alone it along with all the other sentences.

  19. 10.
    ​

    A jointly impossible set of sentences that contains a necessary truth

  20. Yes: ‘1+1=4’ and ‘1+1=2’.
