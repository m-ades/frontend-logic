# PHILO 275 Classroom

LMS for PHILO 275 at Hunter College.

## Tech Stack

- **React**
- **Material UI**
- **Vite**

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the backend on `http://localhost:3000`, or set `VITE_API_PROXY_TARGET` if your backend is elsewhere.

3. Start the development server:
```bash
npm run dev
```
